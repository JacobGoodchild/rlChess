# Your bots

Put each bot in its own folder here, e.g. `Bots/Minimax/`, with the namespace
`RlChess.Players.Bots.Minimax`. Keep everything the bot needs inside its folder.

To keep a version forever (e.g. "Minimax v1") while you keep improving it, run
`python3 tools/freeze-bot.py Minimax v1` from the repository root. See the README section
"Saving a version of your bot".
